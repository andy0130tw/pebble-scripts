# pebble-scripts

For now it contains:

1. **Font**: The scripts to aid generating quality font packs for Pebble. Powered by FreeType. See also https://hackmd.io/@q/pebble-font-pack.
2. **i18n**: The Traditional Chinese (Taiwan) language pack for Pebble.

Content from this repo will likely be synchronized to [my fork of coredevices/pebbleos-translations](https://github.com/andy0130tw/pebbleos-translations) from time to time. Feel free to contribute unless your work contains LLM-generated content.
